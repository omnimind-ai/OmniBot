# v0.7.0.4 Beta

本次更新修复小万新建对话被终端安装状态阻塞的问题，并完善英文界面。

- 修复终端环境安装失败时，新建小万对话无法发送消息、已有对话却能正常使用的问题。新旧对话现在统一走原有发送流程，终端安装提示和重试入口仍然保留。
- 完善 Agent 名称、权限提示、任务执行状态、终端设置和网页浏览等界面的英文文案，并修复切换语言后内置 Agent 名称和描述未及时刷新的问题。

对应变更：#573、#574。

验证：新建对话修复的 105 项相关测试通过，覆盖安装未开始、进行中和失败时的新旧对话发送、历史与用户消息保留，以及安装完成不重复发送；该修复已完成真机验证。0.7.0.4 正式签名包的构建及覆盖安装验证仍需在发布前完成。

版本号为 0.7.0.4，Android versionCode 为 21，按现有四段版本规则发布到 beta 渠道。
