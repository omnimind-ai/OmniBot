## 录制来源与范围

独立 debug 包仅临时修改 applicationId 后缀与应用名称；真实首页、Agent 配置页、聊天页、Android Na 适配器和 Flutter 显示组件均来自对应 PR 提交。通过真实 UI 完成首次引导、配置和发送，ADB 负责点击、输入和原始截图/录屏。普通 App 入口取代先前的 `pr_device_probe.dart`。

手机经 USB 连接本地实际 Na HTTP/SSE 服务；模型输出为确定性旅行样例，没有使用生产账号或真实用户聊天。两段 MP4 已全量解码检查，并抽帧核对实际页面。文件哈希、尺寸与来源提交保存在各目录的 `manifest.json`。

上轮记录的 #566 `session/new` 连接失败已进一步复现并修复：空闲连接被服务器关闭后，写请求仍可能复用它。本轮改为写请求使用新连接且 I/O 失败不重发，46 项原生测试及手机 7/9/12 秒三轮验证通过。详见[根因、修复前后真实 App 录像与逐轮计数](pr566/connection-20261103/README.md)。生产网络与 HTTPS 延迟不属于本地样例验收范围。

诊断构建排除了已有独立 Pi 资源校验任务 `verifyPiAcpBundle`。本次附件只展示真实界面操作，不证明生产鉴权、正式版打包、真实模型全链路或 16.7 毫秒帧耗时达标。
