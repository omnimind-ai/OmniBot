# v0.6.2.1

本次小版本集中修复 Codex 模式的计划展示和确认记录恢复。

- 修复 Plan 模式完成后没有计划正文：对齐 Codex ACP 与 Kotlin SDK 的计划标识字段，保留计划内容及更新身份。
- 修复已处理的计划确认在重启后重新出现操作按钮：精简卡复用既有确认结果持久化，失效历史请求不再提供操作。
- 增加 Codex 模式的可执行回归：计划确认与拒绝、Plan / Default 切换、取消、连续对话和重启恢复。

此版本使用四段版本号，按现有发布规则进入 beta / 预发布渠道。测试采用 Android 模拟器中的真实 Codex 与官方 ACP，本机受控模型服务提供回复，不代表真实模型输出质量验证。

已知限制：Android / proot 环境的默认命令沙箱仍依赖内核能力；本版本不包含 DSH 沙箱修复，也没有降低沙箱权限来宣称兼容。

验证：Kotlin 18 项、Flutter 298 项、实际 Codex CLI 10 场景、模拟器 App 操作 42 步通过。物理手机仍待真机验证，详见 [回归记录](../testing/codex-0.6.2.1-verification.md)。
