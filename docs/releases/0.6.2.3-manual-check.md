# 0.6.2.3 模拟器人工验收

先在设置确认版本 0.6.2.3；选择小万和一个已配置可用模型。每项独立记录
通过/失败/未测；用户尚未执行时不得预填通过。模拟器验证不代替真机验收。

## 推荐顺序

| 项目 | 操作 | 预期 |
| --- | --- | --- |
| 基本对话 | 新建小万会话，发送“只回复：你好0623” | 正常完成一轮，无重复用户消息、无永久转圈 |
| HTML 预览排版 | 让小万输出下方准备好的 preview.html/preview.docx 链接及表格；滚动、打开大预览再返回 | 预览、标题、表格不重叠；无需重新生成文件 |
| 权限菜单返回 | 打开 Agent permissions/权限菜单，不选选项，按 Android 返回；重复两次 | 只关闭菜单，不退出 App，不改变权限 |
| 终端取消 | 发“用 terminal_execute 执行 sleep 60; echo SHOULD_NOT_FINISH”。运行中点停止，再发“用 terminal_execute 执行 echo RECOVER_0623” | 第一轮取消，App 不退出；第二轮输出 RECOVER_0623 并完成 |
| 工具错误详情 | 发“用 terminal_execute 执行 sh -c 'echo ERROR_0623 >&2; exit 7'，不要重试” | 工具标为失败，展开能看到退出码7和ERROR_0623；下一轮仍可聊天 |
| 文件分页 | 使用下方分页提示词 | 第二页校验值是 BLUE-482；没有把原文件截断或把模型猜测当正文 |
| 草稿与附件 | 写未发送草稿，选一个测试附件，切换到另一已有 Harness 再切回来 | 草稿/附件按既定会话保留，不自动发送，不出现在错误会话 |
| 会话与历史 | A 会话发“本会话标记 ALPHA0623”，B 发“本会话标记 BETA0623”；切换回来，再关掉并重开 App | 已发送记录和各自结果仍在，A/B 不混串；不要把要求模型永远逐字记住等同历史持久化 |
| 上下文设置 | 长按输入框上下文圈，记下原值，改32k，切换模型和重启后再查看 | 用户设置按原配置语义保留，无数据时显示空环；测完恢复原值 |
| 手动压缩 | 在已有多轮会话执行菜单中的 compact 或 /compact，完成后继续问上一轮任务 | 原历史仍能查看，后续能继续；这是手动压缩，不能算自动压缩通过 |
| 自动预算压力 | 上下文设32k后使用下方长文件提示词；观察压缩/预算处理，再重启继续询问任务 | 不 OOM、不重复执行已完成工具、失败不永久卡住；最终值GREEN-917；读完文件本身不能证明产生了持久摘要，需另看压缩事件/checkpoint |
| 定时任务 | 让小万创建约3分钟后的测试任务，内容“写入 /workspace/qa-0623-20260910/scheduled.txt，内容 SCHEDULE_0623”；切后台等待 | 任务执行结果可见、文件存在且内容准确；测试后删除测试任务 |
| 关闭/删除 | 使用独立测试会话运行长命令，关闭会话；另建会话继续。完成后删除该测试会话，再重启 | 正式终态正常，剩余会话可用，被删会话不复活；不删除原有重要历史 |
| 配置与取消恢复 | 改用另一已配置模型发送短句，再切回；MCP/权限提示出现时拒绝或停止，再发送普通短句 | 拒绝/停止有明确结果，后续请求可用；“已配置”不等于服务商一定可访问 |


长文件提示词（会调用多次工具，建议基础项通过后再做）：

```text

直到 hasMore=false，不跳页、不使用其他工具查尾部。
不要复述全文，最后只报告 CONTEXT_END_0623 的值。
```

测试输入为本地生成的脱敏文本：pages.txt 第一段2300个A、第二段2300个B，
中间标记 PAGE_TWO_0623=BLUE-482；context.txt 为800行编号的重复字母数字文本，
结尾 CONTEXT_END_0623=GREEN-917。通过 App UID 写入新的测试目录，不覆盖既有文件。

## 不应混淆的验收范围

- file_read/terminal_execute 先在“小万”验证；Codex/DSH 沙箱仍有已知失败，
  不能因错误提示可见就把沙箱记为通过。
- 精确并发、MCP SSE 断流、大历史 OOM 和 checkpoint 可靠边界继续使用既有
  自动化测试与脚本。人工看一次回复不能覆盖这些场景。
- 完整用户操作是否通过由本轮实际结果决定；失败请记录项目号、会话、操作、
  现象和截图，不需要重发整段私人历史。
