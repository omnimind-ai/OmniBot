# 小万 0.6.2.3 测试版

本版合并既有候选的 14 类修改，详情见 [合并清单](0.6.2.3-merged.md)：请求前上下文预算、摘要与历史恢复、超限和 Provider 错误、文件与图片工具、ACP 生命周期、MCP 与权限、终端停止、Codex 结果与历史、聊天切换与输入、聊天展示、权限弹层返回、文件预览排版、定时任务与配置、可执行回归。

后续补充：历史消息头像跟随所属会话；DSH 插件参考技能按实际安装的官方文档生成；DSH 依赖固定到 0.1.5-rc.1 并更新准备版本，使旧安装重新准备。未增加官方 ACP 尚未提供的四个 preset 切换。发布环境同步主线 JDK 21 修正。

验证：候选离线回归通过；DSH 聚焦测试、debug 构建与模拟器覆盖安装通过，官方 ACP 初始化、空目录及重复技能发现通过。生产签名 APK 由 Release APK 工作流构建。

限制：这是测试版，**待真机验证**。Android 模拟器的工作区沙箱仍不可用，更新依赖不等于修复内核隔离；动态 Cordis 插件只在当前进程存活。完整空磁盘安装、所有 Provider 和全部外部 Harness 尚未完成验收。DSH 模拟器升级经临时本机网络转发完成，直连下载失败仍有网络依赖。

新版 App 内真实模型回合已尝试，官方 ACP 返回 `Internal error: turn failed: Connection error.`；没有执行到本轮工具验收。因此新版完整模型/工具链验收未通过，不能用 initialize 成功替代。
