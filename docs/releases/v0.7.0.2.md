# v0.7.0.2 Beta

本次更新为小万模式加入表情包回复，并改善模型 API 临时故障时的恢复能力。

- 小万可以在庆祝、轻松互动等合适场景发送静态表情或 GIF，支持点击预览和历史记录恢复。默认每次回复最多一张，避免连续主动发送；用户明确要求发送或停止时优先遵从。严肃任务仍以清楚、有效的文字回复为主。
- 模型尚未输出时，临时网络错误、服务不可用和可恢复限流默认最多自动重试两次，通常等待 1 秒、2 秒，并遵守服务端的 Retry-After。长时间限流、额度不足和配置错误会直接提示。
- 重试沿用同一轮对话，不新增用户消息。已经输出文字、推理或进入工具执行后不会自动重放；点击停止也会取消重试等待，避免重复操作。
- 表情检索不可用时退回普通文字回复；表情资源保存在本地附件中，GIF 保留动画。

验证：相关 Android、Flutter 和故障夹具回归通过；PJD110 实机已验证表情发送节奏、GIF、预览、重启恢复，以及 503 后自动恢复、重试耗尽、流式中断不重放和取消等待。行为验收使用开发构建，重试异常由本地 HTTP 故障服务受控注入。

版本号为 0.7.0.2，Android versionCode 为 19，按现有四段版本规则发布到 beta 渠道。
