# 0.6.3.1 更新说明（候选草案，尚未发布）

范围：对照本地 v0.6.3 标签与当前候选源码、对应测试记录整理。以下是版本候选改动清单，不等于整包已通过发布验收。

## 更新弹窗精简版

- 新增本地模型服务（实验性），按需下载，支持高通 HTP 加速。
- 改进会话同步、流式回复、长任务上下文处理和异常恢复。
- 增强图片与 PDF、Word、Excel 附件读取及重启后回读。
- 新增授权后的通知读取，完善插件应用入口与录制回放。
- 优化电脑 Codex 会话管理、模型配置保存和文件操作反馈。

## 完整改动

### 本地模型服务（实验性）

- 从小入口按需下载官方 OmniInfer 组件和模型，在手机本地启动模型服务；主 App 不内置模型权重。
- 提供 Qwen3 / Qwen3.5 模型选择，沿用现有 Provider 接入聊天。
- 支持 CPU 与高通 Hexagon HTP 路径；启动时选择后端，记录已验证配置并复用下载文件。
- 修正本地模型请求中多个开头 system 消息的兼容问题。
- 验证范围：HTP 真机推理、流式取消恢复和工具调用已验证；0.8B 正式 Agent 文件任务未正确完成。自动后端选择的最终整包真机验收待完成，不能宣传为可靠离线 Agent。

依据：[HTP 实测](../testing/omniinfer-htp-phone-2026-09-18.md)、[按需组件与后端选择](../testing/omniinfer-auto-backend-20260918.md)。

### 会话、流式回复与长任务

- 修正远程会话归属和事件投影，减少切换或创建会话后回复落错页面的问题。
- 改进流式文本完成时的显示及分段动画，处理已结束但文字仍未完整显示的问题。
- 改进上下文超限后的有界恢复、摘要检查点处理与错误提示，保留既有历史和任务身份。
- 修正短任务结束时前台服务启动/停止的竞争，避免部分附件发送场景崩溃。
- 限制：长任务不能保证自动完成；已有大文件任务仍有失败记录，不能宣称“无限上下文”或彻底消除断线问题。

依据：[远程会话修复](../testing/codex-remote-demo-20260918.md)、[流式显示](../testing/dsh-streaming-layout-20260917.md)、[上下文恢复](../testing/context-recovery-20260919.md)、[附件与服务生命周期](../testing/attachment-runtime-20260919.md)。

### 图片、文档与文件操作

- 增强文本 PDF、Word / Excel 正文读取，明确扫描件、不可解析文件等边界。
- 修正持久附件的工作区路径解析，支持退出、重启后的历史附件回读。
- 完善图片附件传递、历史保留和模型能力不匹配时的提示。
- 完善文件编辑无变化、参数无效或读取失败时的反馈，避免把未发生的编辑报告为成功。

依据：[PDF](../testing/pdf-body-read-20260919.md)、[Office](../testing/office-body-read-20260919.md)、[候选包实测与边界](../testing/release-candidate-20260919.md)。

### 电脑 Codex 协作与会话管理

- 改进同一远程 Codex 会话在手机与电脑间的接续、外部消息同步及 Bridge 中断恢复。
- 关闭远程模式时隐藏侧边栏「电脑」入口；保存过配对不等于开启远程模式。
- 增加电脑会话快捷新建和标题/工作目录搜索，修正 sessionId 识别与重复点击创建问题。
- 未配对时提供连接入口；防止迟到配置读取覆盖刚保存的开关状态。
- 限制：已有真机双向同步和模拟器中断恢复证据，但最新开关与冷启动流程仍待真机验收；不宣称公网、电脑休眠或所有桌面 GUI 场景均通过。

依据：[会话管理](../testing/computer-session-entry-20260919.md)、[远程恢复](../testing/remote-write-recovery-20260919.md)。

### 通知读取

- 增加系统通知访问授权及按应用控制，让 Agent 读取允许应用的当前通知、等待通知变化。
- 真实 Agent 已验证读取通知与记忆回查；该能力读取系统通知，不是任意读取短信收件箱或应用内部数据。

依据：[通知访问与真机测试](../testing/notification-access-20260917.md)。

### 插件应用与工作区

- 恢复 Vibe Builder 和生成应用的打开入口、用户确认后的桌面快捷方式。
- 完善插件启停、卸载、数据保留、工具发现/分页及构建验证反馈。
- 不将单个演示应用通过验收扩大为“模型能够稳定自主生成任意 App”。

依据：[插件应用恢复](../testing/vibe-app-restoration-20260917.md)、[工具分页](../testing/vibe-pagination-20260919.md)、[候选包验收](../testing/release-candidate-20260919.md)。

### 录制、回放与运行记录

- 改进录制控制条对页面观察的干扰、回放时页面遮挡、动作名称与运行记录显示。
- 修正 Release 混淆下的运行日志序列化，完善参数与函数元数据编辑反馈。
- 部分原始及参数化回放已实测；复杂自动增强仍存在失败案例，不作全面成功承诺。

依据：[录制回放](../testing/recording-page-20260919.md)、[运行记录](../testing/release-runlog-serialization-20260919.md)、[函数元数据](../testing/function-metadata-edit-20260917.md)。

### 模型配置与工具执行

- 修正 API Key 编辑/保存时序、服务商身份绑定与模型配置反馈。
- 移除独立、安全读取工具每批最多四个的固定限制；写入、终端和设备操作继续遵守串行边界。
- 这是既有工具调度改进，不是新增“多智能体并行”。超过四个工具实际同时执行仍待真机验收。

依据：[配置保存](../testing/provider-key-save-20260916.md)、[工具并发](../testing/tool-parallel-no-fixed-cap-20260918.md)。

## 不重复列为新增

Kimi / DeepSeek WebUI、Harness 切换、多智能体并行本身是既有能力。只在相应功能有本次具体改进时列出。外部 presence APK 的群聊尚未认定已进入本仓库，不计入本候选更新。

## 发布与展示状态

源码候选版本已设为 0.6.3.1 / versionCode 17，尚未正式发布。正式发布前仍需以最终同一安装包完成验收；各记录来自不同时间与不同测试包，不能简单合并为整包已通过。

AppUpdateManager 从 releaseNotes / notes / body 读取说明，更新弹窗滚动显示 releaseNotes。发布工作流目前 generate_release_notes=true；只提交本文不会自动更新用户弹窗。发布时应将精简版写入 Release 正文，并放完整说明链接，核验更新服务实际返回对应版本和文字。当前未创建发布 tag、上传 APK 或推送更新。
