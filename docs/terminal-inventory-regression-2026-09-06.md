## 边界与行为

沿既有“EnvironmentSetupLogic → EmbeddedTerminalSetupManager → SpecialPermission → TermuxSettingPage”修改，不涉及 ACP 生命周期、配置缓存或额外重试。

- `ready=true`：检测确认可用；`false`：检测确认未就绪；`null`：检测失败或未返回结果。跨原生/Flutter 边界保留这个区别，不将未知转为缺失。
- 单个组件在独立 shell 子进程中检测。版本命令先检查退出状态，再截取首行；失败返回 ERROR，其他组件继续。基础 cwd 检测失败仍终止整次请求。
- 解析保留空版本字段，也接受上游整体 trim 后的末行空版本；未知状态不冒充 MISSING。
- 整体检测失败时页面显示检测错误，不展示误导性的 0/14，不全选安装；单项未知不可选择。已确认缺失项仍可选择，安装前只要求所选组件的状态有效，避免无关异常阻断安装。
